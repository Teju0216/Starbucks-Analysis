# ☕ Starbucks Sales & Customer Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Starbucks Analysis Dashboard** developed using **Power BI** to analyze sales performance, customer behavior, product trends, and business insights.

The dashboard helps understand:

* Sales trends over time
* Customer purchasing behavior
* Top-performing products
* Revenue distribution
* Store performance analysis
* Business decision insights

---

## 🚀 Features

* 📊 Interactive Power BI Dashboard
* 📈 Sales Trend Analysis
* 🛍️ Product Category Performance
* 👥 Customer Behavior Insights
* 💰 Revenue & Profit Analysis
* 🌍 Region/Store-wise Comparison
* 📅 Time-based Filtering
* 📉 KPI Monitoring
